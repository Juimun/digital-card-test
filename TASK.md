# Тестовое задание

Backend-приложение «цифровая визитка», презентующее меня как специалиста.

## Требования

- Стек: Git, TypeScript, Node.js, NestJS, Prisma, GraphQL, Docker.
- API через Apollo Sandbox, отдающее:
  - профиль (имя, описание, ссылки на GitHub/LinkedIn);
  - список навыков;
  - опыт работы (компания, должность, период, достижения);
  - проекты (название, ссылка на репозиторий).
- База данных автоматически готовится и заполняется данными при запуске.
- Пример запроса:

  ```graphql
  query {
    profile {
      name
      description
      skills { name }
      experience { company position }
      projects { name }
    }
  }
  ```

- Архитектура, структура API и БД - на усмотрение исполнителя, с разумным разделением ответственности между бизнес-логикой, доступом к данным и GraphQL-слоем.

## Критерии оценки

Оценивается не объем кода, а качество инженерных решений:

- структура приложения и разделение ответственности;
- работа GraphQL с вложенными данными;
- взаимодействие с базой данных;
- инициализация и заполнение базы данных;
- читаемость и поддерживаемость кода;
- корректная работа приложения после запуска с нуля.
